# 小團體 - 簽到系統

小型上課團體專用的出缺勤管理系統，使用 Google Apps Script + Google Sheets 建構。

## 功能概覽

**學員端**
- 登入後查看個人儀表板
- 上課前可線上請假
- 上課中可簽到
- 查看自己的出缺勤紀錄、分組、組別成員

**管理端（老師 / 管理員）**
- 新增、修改、刪除課程（含時間、地點/會議連結）
- 開始上課 / 結束課程
- 出缺席管理：查看每堂課的出缺席狀況，可手動調整狀態
- 分組管理：將學員分配至 1~8 組，指定組長
- 成員管理：新增 / 刪除成員、解鎖帳號

## 規則

| 規則 | 說明 |
|------|------|
| 簽到 | 課程狀態為「進行中」時才能簽到 |
| 請假 | 只有課程「尚未開始」時學員可自行請假 |
| 曠課 | 課程結束時未簽到且未請假者自動標記曠課 |
| 鎖定帳號 | 曠課 1 次（不分實體/線上）即鎖定 |
| 鎖定帳號 | 實體課程連續請假 2 次即鎖定 |
| 線上課程 | 請假不計入連續請假次數 |
| 管理員協助 | 可在任何時候手動修改學員出缺席狀態 |

## 技術架構

- **前端**：單頁 HTML（Bootstrap 5）
- **後端**：Google Apps Script
- **資料庫**：Google Sheets（members / courses / attendance 三張表）
- **部署**：透過 Apps Script 部署為 Web App
